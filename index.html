PMH = giá đen − giá đỏ. Bỏ qua mọi số trong dòng “Chọn 1 trong các khuyến mãi”.

Thêm một đợt quét từ scraper

Chạy promotion_scraper.py trên máy bạn, rồi chọn file scan_YYYY-MM-DD.json nó xuất ra. Cột mới sẽ nối vào lịch sử, và SKU nào đổi giá đen sẽ được gắn cờ.

{ "date": "06-Oct",
  "rows": [ { "model": "iPhone 17 256GB", "rrp": 28990000, "pmh": 2000000 } ] }

Dữ liệu nhập chỉ lưu trong trình duyệt này. Muốn mọi người cùng thấy, thêm đợt quét vào data/data.js (mảng SCANS) rồi đưa web lên lại.
